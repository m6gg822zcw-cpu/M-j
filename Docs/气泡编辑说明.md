# 手动气泡排版

完成某格漫画后，进入作品的「漫画」页，点击该格下方的「调整气泡」。书架提供「离线试用气泡编辑」，可以不连接任何 API 体验整条链路。

## 操作

- 点气泡或上方对白标签选中。
- 拖气泡本体移动位置，尾尖保留原指向；拖青色角点调整宽高，拖橙色圆点调整尾尖。
- 可以改气泡内文字、说话者、字号，选择对白、心声、旁白框，显示 / 隐藏姓名或尾巴。
- 「精细调整」用百分比调整位置、尺寸与尾尖；上方列表也能选中隐藏的气泡，再开启显示。
- 底部支持新建、删除、置顶、撤销 / 重做与恢复原对白布局。最多每格50个气泡，撤销保留最近60次操作。
- 关闭时有未保存修改会提示保存或放弃；点击「保存」后才写入工程。

气泡文字独立于原分镜对白，改字不会修改原小说或原始图片。默认气泡由该格对白、旁白、音效产生；删除全部并保存后会保持纯图，直到你主动恢复原对白布局。

阅读、全屏预览、PDF、PNG 和离线 HTML 会使用同一绘制器与已保存位置。重新打开应用、备份再导入也会保留排版。字号按画格同比缩放，较长文字会适当缩小；达到下限仍放不下时，保存与导出会要求放大气泡或减少文字，避免对白被静默裁掉。

重绘某格会保留手工排版。由于新画面人物可能移动，请重新核对气泡和尾尖；在编辑过程中图片已被重绘，或另一窗口先保存了该格，旧编辑器会提示重新打开。

## 源码约定

`ComicPanel.lettering` 为可选字段，旧 v1.0 工程没有该字段仍可解码。保存后的空数组是明确的“无气泡”，与未编辑状态不同。

`BubbleRect` 和 `BubblePoint` 保存原图比例坐标，`ComicLettering` 保存修订版本与有序气泡列表。手工排版不进入生图提示词指纹，不会让原图变成待重生成。`Repository.saveLettering` 原子保存，并校验原图文件与修订号；普通流水线 checkpoint 会保留磁盘上的手工气泡。

`BubblePainter` 用固定比例画布排文字，复用排版结果；拖动本体只改位置，不重新请求 API。阅读图离屏释放自身位图引用，继续使用有限缩略图缓存。

## 验收边界

核心几何、保存、旧数据与备份兼容已自动测试。UIKit 实际绘制、真机手势与导出视觉效果尚需在 Apple 环境构建后验收；详见 BUILD_IPA.md。

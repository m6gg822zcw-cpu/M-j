# v1.1.2 · 文件导入、整页漫画与声音显示

版本 1.1.2，build 4，2026-10-24。

## 本轮修改

- 选择器允许通用文件后，按实际扩展名校验；外部 URL 使用后台 NSFileCoordinator 协调读取，保持 security scope，并限量复制到 App 临时目录后解析。文件大小也按实际读取量检查，临时文件最终清理。取消不弹失败，成功明确反馈作品和章数；已写入而刷新失败时提示无需重复导入。
- 漫画每页可选 1／2／4 格，默认 4 格；阅读、PNG、PDF、HTML 都调用同一页绘制方法，同一个 BubblePainter 仍按每格的实际图片区域绘制。逐格编辑、重绘和详情保留。整页是本地组合，不让生图模型画一张多时间线混杂图，不额外调用 API。
- 提示分镜模型按完整叙事节拍安排镜头，合并同一时刻的短段、对白和反应，避免空泛微动作占满一个镜头；关键时间、地点和状态变化仍分镜，不虚构原文没有的剧情。
- 默认音效层不直接显示“雨声/环境声/无”等标签。已知的确切环境声可转换简短拟声词；“雨声：淅沥”只取“淅沥”，未知描述不猜。原始 sfx、对白和旁白保持原样，手工气泡层（含空层）优先。

## 本地验证

Swift 6.0.3 Linux 全部 87 项核心测试通过，包含 6 项顺序分页/几何测试、9 项声音显示测试以及原有 NAI 请求、备份和气泡兼容测试。App Swift 语法解析及 shell 语法检查通过，这些不替代真实 iOS 编译。

## 原生检查入口

Scripts/simulator_smoke.sh 会在全新临时模拟器先正常启动截图，再以仅 DEBUG 的显式参数执行实际导入/导出检查。正常启动和 Release IPA 不运行这些检查。

检查内容：真实 importFile 路径导入 TXT、Markdown、章节 JSON 和离线 MOXU；比对存档原文与未修改的源文件；对测试工程存档四个画格，覆盖手工文字、默认拟声词、空手工层和原示例；PNG 每页 1／2／4 格应分别导出 4／2／1 页，并检查原生 PNG 解码、PDF 页数和 HTML 内嵌图。输出结果与实物在构建日志 artifact 的 smoke/native 目录。

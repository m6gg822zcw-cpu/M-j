## 首次设备验收建议

1. 用示例导入测试书架、章节切换、只分镜模式和人物编辑，切换浅色 / 深色与大字体。
2. 配置一个真实文本模型，只做第一章分镜，核对人物、说话者、原文段落与结尾记忆。
3. 上传两个人物定妆图，从单人、双人、脱外套、摘围巾和左右手交物场景逐格试生成。
4. 在请求过程中切后台或断网；恢复时先核对平台记录，确认没有静默重复收费请求。
5. 在离线示例移动气泡与尾尖并保存；重启后导出 PDF / PNG / HTML，核对实际图片区域内的位置，再备份、重新导入核对。详见 BUILD_IPA.md。

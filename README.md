# 墨序 · iOS 小说漫画工作室 v1.1.2

原生 SwiftUI 应用，最低 iOS / iPadOS 17。把导入的小说按章、按批改编为分镜，再使用自己的生图服务绘制画格。

**v1.1.2 修复文件导入、增加每页 1／2／4 格阅读与导出，并修正“雨声”等音效标签的默认显示。** Linux 87 项核心测试通过；本版真实 iOS 构建及模拟器内导入、导出检查正在验证。上版结果和本版说明见 [导入与整页漫画修复记录](Docs/v1.1.2_导入与整页漫画.md)。

新版加入出图后的气泡编辑：拖动位置、缩放、尾尖、文字字号、撤销重做和本地保存；阅读与 PDF / PNG / HTML 导出共用同一排版。可先在书架点「离线试用气泡编辑」，无需 API。给 Codex 生成 IPA 请先读 [构建交接](BUILD_IPA.md)。

## 打开与安装

1. 在装有 **Xcode 16 或更新版本** 的 Mac 上解压，打开 `Moxu.xcodeproj`，选择 `Moxu` scheme。
2. 先选择 iPhone 或 iPad 模拟器，点击 Run。项目只依赖本地 `MoxuCore` 包和系统 zlib，不需要 CocoaPods、Node、网页容器或额外代码生成器。
3. 安装到自己的 iPhone：在目标的 **Signing & Capabilities** 选择自己的 Team，将 `com.yourname.moxu` 改成自己的唯一 Bundle Identifier，连接设备，按 Xcode 提示完成配对与开发者模式设置，然后 Run。

也可在工程根目录运行：

    bash Scripts/build.sh

它会先运行打包校验测试、核心测试，再构建模拟器应用。`Scripts/archive_unsigned.sh` 可在有 Xcode 的 Mac 上生成**需要自行签名**的 `build/Moxu-unsigned.ipa`。具备本机证书和描述文件后，`Scripts/archive_signed.sh` 可导出签名 IPA。附带的 GitHub Actions 工作流提供未签名打包和日志下载；已在你的 GitHub 仓库启用并成功执行云构建，见 [构建结果](https://github.com/m6gg822zcw-cpu/M-j/actions/runs/40105041249)。

## 文件导入、整页漫画与声音（v1.1.2）

书架导入支持在「文件」App 中选取 TXT、MD/Markdown、JSON、EPUB、DOCX、文字 PDF 和 MOXU。选择器先允许通用文件，再校验扩展名，避免部分云盘把文稿标为 `public.data` 后无法点选。外部文件在后台协调读取并复制为临时副本，读取完成后清理；原文件不移动、不修改。成功时书架显示作品与章数，失败时显示文件名及原因。扫描 PDF 仍需要先 OCR，未下载完成的云盘文件可能需要先在「文件」App 下载。

在作品「漫画」页选择 **每页 1／2／4 格**（默认 4 格）。相邻分镜在本地组成整页，点页可放大；PNG、PDF、HTML 使用相同布局。展开「逐格编辑、重绘与详情」可继续调整原图上的气泡和单独重绘。整页排版不裁切原图，不重写原文、对白或手工气泡，不额外发送生图请求。新分镜提示也会合并同一时刻的短段、对白与反应，避免把无信息的微动作机械拆格。

默认排版不再把“雨声”“环境声”“无”等分类标签直接印出来：明确的“雨声”显示为“淅沥淅沥”，独立拟声词保留，未知环境描述不猜写。对白或原文里的“雨声”照常保留。已经手工保存的文字和气泡层优先；若手工层中仍写着“雨声”，可在气泡编辑中修改或恢复默认布局。

## NAI 中转请求格式（v1.1.1）

在「画师串 → 编辑 → 生图请求格式」选择 **NAI**，并将该画师方案设为生图连接默认方案或作品的画师方案。漫画、人物定妆图和提示词预览都会采用 NAI 格式。旧方案默认「跟随连接」，仍使用原来的请求格式。

例如中转提供 `https://relay.example.com/v1/images/generations`：连接类型可以保留「OpenAI 兼容生图」，填写这个完整图片接口、平台的 NAI 模型 ID 和密钥，再选择 NAI 画师方案。请求会在这个地址发送 NAI 的 `input / model / action / parameters`，不会因路径像 OpenAI 就改发 `prompt / size`，也不会将完整地址替换为 `/ai/generate-image`。只填根地址时，OpenAI 连接沿用 `/images/generations` 路径，NovelAI 连接沿用 `/ai/generate-image`。

连接页会显示 NAI 的步数、CFG、采样器、种子和参考方式；作品单独指定的画师优先。四组原始画师串保留空白、换行与权重；切换请求格式会将旧图标为待更新，不自动重新生成。NAI 格式选择适用于 NovelAI 或 OpenAI 兼容生图连接，Gemini 连接请继续跟随其原格式。中转必须实际接受 NAI 请求体；仅把 NAI 模型包装成 OpenAI 协议的平台应选「跟随连接」。

本轮新增请求、旧配置兼容、返回格式与流水线测试，Linux / macOS **72 项核心测试通过**，更新版 iOS 编译、启动和归档均成功；真实生图服务未调用。使用细节见 [NAI中转说明](Docs/NAI中转请求说明.md)。

## 第一次使用

1. 在「连接」添加文本 API，填写根地址、真实模型 ID 与密钥，点击「发送一条文本测试」检查返回；该测试会调用服务。
2. 再添加生图连接，选择 NAI、OpenAI 兼容生图或 Gemini，保存后设为默认。没有凭据时不会自行联网测试图片。
3. 在「画师」输入正面、负面、人物、背景四组串，给不同生图连接绑定自己的默认方案。作品也能单独指定画师方案。
4. 在「书架」导入小说，打开第一章，保留「先只制作分镜脚本」，完成首批人物提取。
5. 到「人物」校准身份与衣装，上传单人定妆参考，或生成定妆图。取消「只制作分镜」，开始实际出图。
6. 在「漫画」逐格核对；每格可看组合预览、脱敏请求与原文依据，人工确认一致或单独重绘。出图后点击「调整气泡」，保存拖动、尺寸、尾尖、文字和字号；右上角导出会采用保存后的布局。

「试用一份示例书稿」只导入本地示例，不调用 API。附带 `Samples/章节示例.json` 可用于导入测试。

## 已实现

| 模块 | 行为 |
| --- | --- |
| 原生界面 | 书架、章节工作台、人物衣柜、漫画阅读、画师、连接、任务；浅色 / 深色模式，适配 iPhone 与 iPad |
| 导入 | TXT、MD、章节 JSON、无 DRM 的文字 EPUB、DOCX、可提取文字的 PDF、`.moxu` 备份 |
| 逐章改编 | 章节按目录序号独立保存；标题重复不覆盖；默认每批约 3000 字符，可调 1500—6000 |
| 记忆 | 每批摘要与结尾状态，本章结束融合为一份总记忆；新章节只承接上一章，不读取未来章节 |
| 人物一致性 | 固定编号、身份外观、独立年龄 / 变身阶段、定妆参考；新外观冲突保留为待核实条目 |
| 纸娃娃衣柜 | 基础内层、上装、下装、外套、鞋袜、配饰六层，中英文分别保存；穿着、敞开、脱下、破损、湿透、松散状态逐镜延续 |
| 画师串 | 四组原串保留空白、换行、顺序、括号与权重；不会交给文本模型自动翻译、去重或改写 |
| 生图审计 | 实际请求参数脱敏留存；人物档案、画师或连接参数变化后，旧图提示待更新 |
| 任务 | 串行队列，连续最多排入 10 章；每批 / 每图存档，暂停与恢复；收费图片 POST 不自动重试 |
| 气泡排版 | 出图后手动拖动、缩放、调整尾尖、改字与字号、隐藏、置顶、撤销重做；位置写入工程，统一用于阅读与导出 |
| 中文排版 | 中文对白、心声、画外音、旁白与音效由本地气泡层绘制，提示生图模型不绘制文字 |
| 导出 | 当前章 PDF、PNG 分页 ZIP、单文件离线 HTML；完整作品 `.moxu` 备份与恢复 |
| 凭据 | Keychain 保存，工程备份不包含连接配置或密钥 |

## API 范围

| 类型 | 请求格式 | 参考图 |
| --- | --- | --- |
| OpenAI 兼容文本 | `/chat/completions` | 支持相应模型的图片输入；可选 `max_tokens` / `max_completion_tokens` |
| OpenAI Responses | `/responses` | `input_image`，默认 `store: false` |
| Anthropic 文本 | `/messages` | 原生 base64 image content |
| Gemini 文本 | `/models/{model}:generateContent` | 原生 `inlineData` |
| NovelAI | `/ai/generate-image`，可读取 ZIP 图片响应 | V4 系列独立角色提示词；V4.5 单人精确参考为实验选项，默认关闭；单人图生图 |
| OpenAI 兼容生图 | 无参考用 `/images/generations`，有参考用 `/images/edits` | multipart `image[]`；可另填完整编辑接口；可关闭参考，只文生图 |
| Gemini 生图 | 原生 `generateContent` | 多张 `inlineData`；可关闭参考 |

根地址和完整接口地址均可填写，应用会避免重复拼接常见端点。模型 ID 由你输入或从平台读取，未硬编码容易退役的 OpenAI / Gemini 默认模型。NAI 候选是本地列表，查看候选不代表服务器连通。

兼容意味着**服务支持上表的请求与响应格式**。异步任务 ID / 轮询协议、ComfyUI 工作流、各类 SD WebUI 私有接口和平台独有签名规则没有通用适配。API 参数可能随平台改变；详细配置与扩展方式见 [API说明](Docs/API说明.md)。

气泡操作详见 [气泡编辑说明](Docs/气泡编辑说明.md)。离线示例是坐标测试图，不是 AI 生成漫画。

## 一致性与运行边界

外观档案、参考图、角色标签和人工校对共同减少漂移，不能保证任何生图模型每张脸绝对相同。随机种子也不能替代定妆参考。NAI 多人镜头使用分开的角色提示词，本适配器不把多个人物的精确参考叠成一张脸。

角色被“提及”不等于入镜：文本结构要求每个入镜者有当前画格的原文引文，关系与穿脱变化也保留依据。校验可以检查字段、段落覆盖和引文存在，不能代替对原著含义的人工判断。视觉辅助检查默认关闭，开启后额外调用你配置的图片输入文本模型；它只标记差异，不自动重绘。

iOS 不保证长时间后台运行。进入后台会暂停后续队列，在系统允许的时间内保存当前请求；关闭应用后不会持续制作。若服务已收费而本机未拿到结果，任务会等待核实，用户确认后才能重新提交。恢复本地已保存的图片不会再次请求。

扫描版 PDF 没有 OCR，DRM 电子书不解密。归档上限为 512MB、单压缩条目解压上限为 64MB，不支持 ZIP64；大作品可逐章导出。正式上架前需完成 iOS 构建、真实服务联调、设备性能测试，以及自己的签名与分发配置。
